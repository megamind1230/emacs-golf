# Emacs Golf #100 — The Swan Song
**Category:** G. Elisp and automation

Welcome to **Emacs Golf** — fewest keystrokes wins.

## The challenge
Starting buffer:

```
 apple  
BANANA

apple
banana  
CHERRY
cherry
```

Point: beginning of buffer

Target buffer:

```
apple
banana
cherry
```

## Task
One Elisp expression, evaluated once, with nothing pre-defined: trim the whitespace, downcase, drop duplicates and blanks, and leave the three words sorted. This is #100 - post your proudest solution.

## Rules
- Everything is allowed: vanilla Emacs, Evil, Meow, packages, macros, Elisp, custom keybindings, external tools.
- The result must match the target exactly. Correctness beats brevity.
- One key event per stroke: a chord such as `C-a` counts as one stroke.
- Disclose any setup, packages, macros, or custom commands your solution requires.
- Count execution keystrokes, not the time you spent configuring Emacs.

## How to submit
```

Explanation:
```


**The goal isn't to prove one editing style is superior. It's to discover how many different ways Emacs can solve the same problem.**

May the shortest sequence win.
