# Emacs Golf #093 — Window Deja Vu
**Category:** F. Buffers, windows, and navigation

Welcome to **Emacs Golf** — fewest keystrokes wins.

## The challenge
Starting buffer:

```
One window showing notes. Buffers agenda and log exist. Target layout: left window notes, top-right agenda, bottom-right log.
```

Goal:

```
The three-window layout is displayed, AND you have demonstrated saving and restoring it: wreck the layout after saving it, then bring it back. Disclose the register you used.
```

## Task
Build the layout, save it, destroy it, restore it.

## Rules
- Everything is allowed: vanilla Emacs, Evil, Meow, packages, macros, Elisp, custom keybindings, external tools.
- The result must match the target exactly. Correctness beats brevity.
- One key event per stroke: a chord such as `C-a` counts as one stroke.
- Disclose any setup, packages, macros, or custom commands your solution requires.
- Count execution keystrokes, not the time you spent configuring Emacs.
